# 文档设计与审查

规则来源**按需加载**，本 skill 不复制规则正文（H6）：

1. `docs/guides/doc_authoring.md` —— 文档编写规则（分层、模板、引用、术语、图表、可读性、工具）。
2. `docs/README.md` —— 文档分层与 doc policy。
3. `docs/guides/mermaid_authoring.md` —— GitHub Mermaid 渲染约束。
4. `docs/design/known_open_items.md` —— 审查发现的缺陷 / 缺口登记（R11）。

## 0. 边界

| 做 | 不做 → 转给 |
|---|---|
| 文档结构、模板、术语、引用、图表、可读性、导航 | C 代码审查 → `basessd-review` |
| 跨文档边界与单一权威位置 | 架构决策 / 分层取舍 → `basessd-design-arch` |
| 文档迁移计划与回扫 | 代码实现 → `basessd-develop-*` |
| 文档审查结论与台账登记 | 上板 / 测试执行 → `basessd-verify` |

## 1. 三种模式

| 模式 | 输入 | 产出 |
|---|---|---|
| **设计** | 新文档 / 重构目标 | 大纲、规则映射、术语表、迁移步骤 |
| **审查** | 现有文档 | findings（文件:行 + 失败场景）、R11 登记 |
| **优化** | 已定规则 | diff + 检查结果 + 未做项 |

先选模式；模式不清时只做审查，不改正文。

## 2. 设计流程

1. **三问**：读者是谁？读完要能回答什么？哪些可以不写？（`doc_authoring.md` §11.1）
2. **定层**：design / architecture / platform / verification / ledger / revision / guide（`docs/README.md` 分层表）。
3. **定类型与模板**：设计文档骨架、模块七段、ADR 字段（§4）。
4. **定权威位置**：同一事实只能有一处；列出「内容 → 归属」表（§2）。
5. **定术语**：首次出现 `English (中文)`；自造词给主流映射（§6）。
6. **定图**：模块交互 `sequenceDiagram` + `autonumber`；位域 `packet-beta` + 偏移表；状态机 / 流程 / 结构按 §9。
7. **写摘要**：问题、方案要点、范围与非目标（摘要一页）。
8. **写正文**：按模板；引用与可读性按 §5 / §11。
9. **自查**：§11.10 的 10 条；跑 §13 的检查。

## 3. 审查流程（六遍）

按「先结构后细节」；每遍只回答一个问题。

1. **分层与权威**：内容是否在对的层？同一事实是否多处维护？
2. **结构**：摘要 / 章节 / 模块七段 / ADR 字段是否完整？是否有模板外内容？
3. **引用**：是否有 `file:line`、代码路径、规则编号、`RISK-*`/`ISS-*`、日期/版本？实现符号是否「少用、必要不省」？
4. **术语**：首次出现是否双语？同一概念是否只有一个译名？自造词是否标主流映射？
5. **图表**：选型是否正确？时序图是否有 `autonumber`？位域方向是否标注？图是否堆符号？
6. **可读性与导航**：§11.10 的 10 条；TOC / 锚点 / 跨文档引用是否可解析？

## 产物格式

审查 findings 每条一行：

```text
文件:行 — 问题 — 规则（doc_authoring §x / P14 / H6 / R10） — 失败场景 — 建议
```

- 说不出失败场景 = 风格偏好，归 S，不当缺陷报（审查 skill 同判据）。
- 缺陷 / 判定结论必须登记 `known_open_items.md`（R11）；只在回复里列 = 未完成。
- 优化模式先给 `git diff --stat`，再给「改了什么 / 证据 / 未做什么」。

## 常见失败

- 把规则正文抄进文档或 skill（H6），两处漂移。
- 把架构选择 / 主流对照的完整论证留在设计文档。
- 图里堆实现符号；`packet-beta` 不标方向；时序图没有 `autonumber`。
- 只报风格偏好，没有失败场景。
- 未跑 `make docs-check` / `ledger-check` / `review-marks-check` 就宣称完成。
- 把设计文档写成实现索引（函数清单、调用点清单）。
- 提出拆分 FTL 设计文档（本仓明确不拆）。
